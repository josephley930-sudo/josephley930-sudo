# RankForge SEO Agency Website

A modern, premium, conversion-focused static website for a USA-focused SEO agency. The site is designed to generate leads for local SEO, technical SEO, e-commerce SEO, SEO audits, link building, Google Business Profile optimization, and content strategy services.

## Pages

- `index.html` — Homepage with hero CTA, trust badges, client logos, services overview, process timeline, before/after rankings, testimonials, industries, FAQ schema, final CTA, and exit-intent audit popup.
- `services.html` — Dedicated service cards with benefits, process details, timelines, results expectations, and CTAs.
- `about.html` — Agency story, mission, experience positioning, team section, transparency approach, and data-driven strategy messaging.
- `case-studies.html` — Analytics-inspired case study cards with traffic, ranking, ROI, local SEO, and before/after result examples.
- `blog.html` — SEO blog layout with image placeholders, categories, search, internal links, and audit CTA.
- `contact.html` — Lead capture form, Calendly link placeholder, email, WhatsApp button, Google Map placeholder, and quick response promise.

## Design System

- Primary color: dark blue `#011B56`
- Secondary color: green `#6DB109`
- Clean white sections, soft shadows, smooth gradients, premium cards, responsive grids, and lightweight JavaScript.

## Run Locally

```bash
python3 -m http.server 4173
```

Open `http://127.0.0.1:4173/index.html` in your browser.
